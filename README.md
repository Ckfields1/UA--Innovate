# Secure Healthcare Data Management Prototype

## Project Overview

This project was created for the UA Innovate Hackathon in response to a cybersecurity challenge sponsored by A Little Bit of Hope. Our team designed a secure healthcare data-management prototype for storing and retrieving sensitive patient information.

Our project earned first place in the cybersecurity category.

## The Challenge

The sponsor asked our team to design a system that:

- Protects sensitive patient information
- Supports secure storage and retrieval
- Uses authentication and access controls
- Aligns with HIPAA privacy and security requirements
- Provides a simple, user-friendly interface
- Allows healthcare information to be shared securely

## Our Solution

We designed a healthcare data-management prototype with the following security features:

- AES-256 encryption for stored patient information
- Secure password hashing
- Two-factor authentication using time-based one-time passwords
- QR-code authentication setup
- Role-based access control
- Timed session expiration
- Security and activity logging
- Role-specific dashboards
- Patient record search and management
